# Learning engine

Joins pre-production hypotheses to post-publication outcomes.

The existing YouTube metrics work remains the source of platform observations. This module's job is to connect those observations back to the discovery/opportunity records so the next production decision can use our own channel evidence.

## Minimum joined record

- opportunity id
- demand cluster
- topic / audience / awareness hypothesis
- winning package actually published
- hook / structure / duration
- available platform metrics
- interpretation
- confidence
- next experiment

## Rule

Metrics do not prove causation by themselves. Store observations separately from interpretations.

As the channel accumulates enough comparable observations, internal channel evidence should be weighted more heavily than generic creator advice.
