## Rules for using this corpus

- Cite the corpus first. Only go to the web to *add* to it, never to override it.
- If the corpus and a web source disagree, surface the disagreement to Gate 1 — do not silently pick one.
- The contested-credit items (who first used the oil drum) must stay contested on screen. Never state one attribution as fact.
- "20th century," never "19th." Getting this wrong in the opening video is not recoverable.
